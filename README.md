 # Calculadora de Rotas – Veículos Elétricos

 A aplicação consiste numa calculadora de rotas entre cidades, destinada a auxiliar condutores de veículos elétricos com autonomia limitada. A solução permite determinar o caminho mais curto entre duas cidades com base num conjunto de dados reais, utilizando algoritmos clássicos de grafos.
 Foi disponibilizado o ficheiro worldcities.csv, contendo informação de 47.868 cidades, bem como o algoritmo de Dijkstra, utilizado para o cálculo de caminhos mínimos.

 ## Contexto Académico

 Este projeto foi desenvolvido no âmbito da unidade curricular de Estruturas de Dados (ED) e Algoritmos, integrada no 3.º semestre do 2.º ano da Licenciatura em Engenharia Informática da Escola Superior de Tecnologia de Tomar.

 ## Objetivos
 
  - Aplicar conceitos teóricos de Estruturas de Dados em problemas reais
- Implementar algoritmos de grafos para otimização de rotas
 - Desenvolver competências em manipulação de ficheiros em Java
- Criar uma interface gráfica intuitiva e funcional
- Trabalhar com grandes volumes de dados geográficos

 ## Estruturas de Dados Utilizadas
 
- Grafo – representação das cidades e ligações
- Matriz de adjacência – representação das distâncias entre cidades
- Árvore AVL – armazenamento eficiente e balanceado de dados
- ArrayList – manipulação dinâmica de coleções de cidades

## Tecnologias Utilizadas

- Java
- Estruturas de Dados (AVL Tree, Grafos, ArrayList)
- Algoritmo de Dijkstra
- Ficheiros CSV (worldcities.csv)
- Java Swing (Interface gráfica)
